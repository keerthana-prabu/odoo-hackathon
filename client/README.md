# Traveloop 🌍
A personalized travel planning web application built for the Odoo Hackathon 2026.

## Features
- User authentication (signup/login with JWT)
- Create and manage multi-city trips
- Itinerary builder with real city search (Open-Meteo API)
- Budget tracking and cost breakdown
- Packing checklist
- Trip notes and journal
- Shareable trip links
- Admin analytics dashboard

## Tech Stack
- Frontend: React (Vite)
- Backend: Node.js + Express
- Database: MySQL with 7 relational tables
- External API: Open-Meteo Geocoding API (real-time city search)
